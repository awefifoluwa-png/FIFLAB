# Verification record — version 1.0.0

## Automated checks

Run `npm test` and `npm run build`.

The Vitest suite covers:

- A hand-calculated 10 L absolute-volume example (5 kg binder, 17.5 kg total; 19.25 kg with 10% waste).
- Air correction and additional-liquid accounting.
- Cement-free binder replacement handling.
- Incorrect fractions, invalid density/air values, nonfinite values and zero divisors.
- Cube, cylinder and prism volumes; embedded steel displacement and bounds.
- Destructive versus repeated-monitoring specimen counts and unique ages.
- Strength, mass, length, absorption and current-density conversions.
- Sample mean/SD, n=1 behaviour and zero-baseline percent change.
- Separate grouping of cycles, phases, methods, origins and electrodes.
- Unit/date validation, exact control pairing and interrupted persistence runs.
- Fully synthetic sample-project provenance and workspace validation.
- CSV quoting, blank import rejection, unit/mix validation, raw-input round trip and actual XLSX parsing using ExcelJS.

Expected values were checked using elementary independent arithmetic, not generated by calling the implementation under test.

## Browser verification

Development checks exercised:

- Live 10 L recipe result: 5 kg binder / 19.25 kg including waste.
- Save recipe and calculation snapshot; refresh and confirm persistence.
- Calculated strength entry: 100 kN / 2500 mm² = 40 MPa, retaining raw inputs.
- CSV chooser, validation preview and committed import.
- Line, bar and scatter rendering; group counts and plotted replicates.
- Corrosion-monitoring tool navigation and comparison table.
- Actual multi-page PDF and Excel downloads.
- XLSX reopened with ExcelJS to verify sheets and retained observations.
- PDF pages rendered with Poppler; full graph capture and embedded font output inspected. An initial legend-only capture defect was fixed before delivery.
- 390 px mobile layout and navigation.

The app is not a validated scientific method, and these software checks do not establish experimental accuracy, equipment calibration or compliance with an ASTM edition. Researchers must review the inputs and suitability of the selected method. Use separate validation studies for any proposed corrosion-initiation rule.
